Part 1 · Engineering

A simple domain on a hostile backend

Gardens, plants, a target humidity and one rule: the plants in a garden may never need more surface than the garden has. The interesting part is the API.

Latency

200 – 2000 ms

Every response is delayed on purpose. Nothing may block the screen while it waits.

Failures

1 in 10 requests fails

A three-request screen would break 27 % of the time. Failure is the normal case.

The answer

Design for it, don't hide it

Cache, retry, skeletons and ghosts — and never a spinner, never a lie about the data.

Part 1 · Engineering

Signals all the way, with the library's own idioms

Zoneless

Change detection only where a signal changed

No zone.js in the bundle. Every derived value — used area, occupancy, drift — is a computed(), never stored where it could go stale.

SignalStore

Three stores, three scopes

withProps for collaborators, withLinkedState for what resets with a key, signalMethod to follow the route, withHooks on destroy. Mutations return typed verdicts.

Signal Forms

The model is a signal, the rules a schema

The garden and plant dialogs on @angular/forms/signals; the capacity rule is a validator that judges as you type — the same function the server runs.

One contract

DTO types inferred from the API's zod schemas

A schema change is a compile error on the client. Type-only, so nothing of the API reaches the browser.

Part 1 · Engineering

A flaky API, handled once — in one place

1
Stale-while-revalidate cacheA repeat visit renders instantly from memory; identical in-flight reads collapse into one request; hovering a card prefetches its garden.
2
Retry — only when it is safeReads retry with backoff. Every POST carries an Idempotency-Key and the API replays a completed one from memory: a lost answer never creates twice.
3
Races closed by constructionPer-profile cache keys, stale loads discarded by token, writes addressed to the garden they target — switch profiles mid-load and the wrong gardens never flash.
4
Pending is part of the designContent-shaped skeletons on reads, in-place ghosts on writes, an explicit retry when something really fails. No spinners — the build checks.

Part 1 · Engineering

A stylesheet with an architecture, two languages, WCAG 2.2

Styles

Tokens → abstracts → layers

  • Every colour, size and z-index is a token; the dark theme is a remap
  • A breakpoint map, one card recipe, one zone-colour mixin
  • @layer: the foundations can never outrank a component
  • The shared kit is named in BEM
Languages

English and Dutch

  • Compile-time i18n: one build per language, no runtime, no flash
  • 517 messages, the catalog checked in CI
  • Dutch numbers and dates from the locale
  • The Dutch build boots in its own e2e project
Accessibility

Tested, not declared

  • Skip link and a main landmark on every page; focus follows navigation
  • The planner's beds are real focusable SVG elements; the plan also exists as a table
  • The fullscreen planner traps and returns focus like a dialog
  • axe on every screen in both themes
